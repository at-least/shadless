Geist + Geist Mono (OFL — see LICENSE.txt), vendored for the docs site.

The Geist file keeps the wght axis (declared 100 900, like upstream);
Geist Mono is the static 400 upstream declares. Both are latin subsets
(U+0-FF family ranges) — non-latin glyphs fall through the stack, same
as upstream's lazy-loaded subsets.
